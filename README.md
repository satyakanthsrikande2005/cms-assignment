# Production-Ready Content Management System (CMS)

A full-stack Content Management System built using Express.js, MongoDB, React (Vite), and Next.js. The project follows a clean layered architecture and is designed to be scalable, maintainable, and production-ready.

## Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Admin Frontend
- React
- Vite
- Redux Toolkit
- Tailwind CSS

### Public Frontend
- Next.js
- Tailwind CSS

### Features
- JWT Authentication
- Role-Based Access Control
- Dynamic Content Management
- RESTful APIs
- Docker Support
- Responsive UI

## Project Structure

```text
backend/
admin-frontend/
public-frontend/
docker-compose.yml
README.md
```

## Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

### Admin Frontend

```bash
cd admin-frontend
npm install
npm run dev
```

### Public Frontend

```bash
cd public-frontend
npm install
npm run dev
```
